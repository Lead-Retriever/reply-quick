# app/assets

Drop the official logo files here with exactly these names:

| File name | What it is |
|---|---|
| `google-calendar.png` | The official Google Calendar app icon |
| `outlook.png` | The official Microsoft Outlook app icon |

Square PNGs, at least 96 x 96 pixels, with a transparent background.

The firm Calendar tab picks them up automatically. Until they're here, it shows a plain letter tile instead.
